# Catholic App

Catholic App is a web and mobile application designed to improve communication between parishes and their parishioners.

The application will allow users to check parish information such as:

- Office hours
- Mass schedules
- Confession schedules
- Parish announcements
- Contact information
- Parish availability status

Some features will include real-time or manually updated status indicators, for example:

- 🟢 Parish office open
- 🔴 Parish office closed
- 🟣 Confessions available
- 🔵 Mass in progress

## Project Goal

The main goal of Catholic App is to provide parishioners with clear and up-to-date information about their local parishes while giving parish staff an easy way to communicate their availability and services.
